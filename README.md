# Race Day

Race Day is a full-stack web-based event management system designed for South African road running, walking and cycling events.

The system allows organizers to create and manage events, categories and participant results, while participants can browse events, enroll in events, select categories and track their performance history.

## User Roles

### Organizer
- Create, update and delete events
- Manage event categories
- View event enrollments
- Capture participant results

### Participant
- Create an account
- Browse upcoming events
- Enroll in events
- Select an event category
- View personal enrollments
- Track personal results

## Part 1 - System Planning and Database

Part 1 focuses on system planning, relational database design, REST API planning and SQL database implementation.

### Part 1 Deliverables

- Entity Relationship Diagram (ERD)
- REST API Endpoint Plan
- SQL Database Script
- Sample database data
- GitHub Actions CI workflow
